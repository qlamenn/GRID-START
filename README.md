# GRID START 🏎️

Новостной сайт Формулы 1. Учебный проект на Flask.

## Что умеет

- Новости F1 с реакциями (лайк/дизлайк)
- Личный зачёт и Кубок конструкторов (OpenF1 API)
- Календарь гонок 2026 (OpenF1 API)
- Страницы команд, пилотов, трасс
- Регистрация и авторизация
- Профиль с аватаром и сменой пароля
- Обратная связь
- Собственное API

## Технологии

- Python 3.11
- Flask
- SQLAlchemy + SQLite
- Flask-Login
- Flask-WTF
- Jinja2
- OpenF1 API
- HTML/CSS (кастомный, без Bootstrap)

## Установка

```bash
pip install -r requirements.txt
python app.py
